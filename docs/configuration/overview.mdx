## Precedence

Lowest to highest:

<Steps>
  <Step title="Built-in defaults" />
  <Step title="Editor settings (glua.*)">
    Yours, on this machine.
  </Step>
  <Step title=".editorconfig">
    Generic, shared. `indent_style`, `indent_size`, `max_line_length`,
    `end_of_line`.
  </Step>
  <Step title=".prettierrc">
    Generic, shared. `useTabs`, `tabWidth`, `printWidth`, `singleQuote`,
    `endOfLine`, `semi`.
  </Step>
  <Step title=".glua.json">
    This project's rules.
  </Step>
  <Step title=".gluafmtrc.json">
    This project's formatting rules. Most specific, so it wins.
  </Step>
</Steps>

Generic tools get read because a repository that already pins indentation in
`.editorconfig` should not have to say it twice. Anything written specifically
for GLua wins over them, because it was written for this formatter.

## Starting from the UI

Set things up in the settings editor, then export them:

- `GLua: Create Linter Config File` writes `.glua.json`
- `GLua: Create Formatter Config File` writes `.gluafmtrc.json`

Both are seeded from your current settings, so the two are views of the same
thing rather than two places to keep in sync by hand. Both files get completion
and validation while you edit them, from bundled JSON schemas.

<Tip>
  `GLua: Open Settings` jumps straight to this extension's section of the
  settings editor.
</Tip>

## Settings reference

### Activation

| Setting | Default | |
| --- | --- | --- |
| `glua.activation` | `auto` | When `.lua` files are treated as GLua. `auto` only claims files in workspaces that look like Garry's Mod |

### Diagnostics

Every rule takes `error`, `warning`, `information`, `hint` or `off`. See the
[rule reference](/reference/rules) for what each one catches.

| Setting | Default |
| --- | --- |
| `glua.diagnostics.enable` | `true` |
| `glua.diagnostics.undefinedGlobal` | `warning` |
| `glua.diagnostics.realmViolation` | `warning` |
| `glua.diagnostics.unusedLocal` | `hint` |
| `glua.diagnostics.deprecated` | `warning` |
| `glua.diagnostics.argumentCount` | `warning` |
| `glua.diagnostics.argumentType` | `warning` |
| `glua.diagnostics.unknownHook` | `information` |
| `glua.diagnostics.netMessage` | `warning` |
| `glua.diagnostics.netReadWriteMismatch` | `warning` |
| `glua.diagnostics.missingAddCSLuaFile` | `warning` |
| `glua.diagnostics.globalWrite` | `off` |

### Completion, hover, hints

| Setting | Default | |
| --- | --- | --- |
| `glua.completion.callSnippets` | `true` | Insert parentheses and parameter tab stops |
| `glua.completion.filterByRealm` | `true` | Hide members that cannot exist in this realm |
| `glua.hover.wikiLinks` | `true` | Link to the wiki from hover |
| `glua.inlayHints.parameterNames` | `true` | Parameter names at call sites |
| `glua.inlayHints.realm` | `false` | The inferred realm at the top of each file |

See [the formatter page](/features/formatter#options) for the full table.
