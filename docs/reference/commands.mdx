## Command palette

All of these are under the **GLua** category.

| Command | What it does |
| --- | --- |
| **Show Net Message Graph** | Opens a markdown report of every net message: who registers, sends and handles each one, and whether the payloads line up |
| **Create Formatter Config File** | Writes `.gluafmtrc.json` seeded from your current settings, and opens it |
| **Create Linter Config File** | Writes `.glua.json` seeded from your current settings, and opens it |
| **Open Settings** | Jumps to this extension's section of the settings editor |
| **Re-index Workspace** | Rescans every Lua file. Useful after a large change on disk, like a branch switch |
| **Restart Language Server** | Restarts the server process |
| **Treat This File As GLua** | Forces GLua analysis for the current file |
| **Treat This File As Plain Lua** | Hands the current file back to your other Lua extension |

The last two are also reachable by clicking the status bar item, which shows the
current file's realm.

## Code actions

Offered on the lightbulb when the cursor is on a relevant finding.

### Quick fixes

| On | Fix |
| --- | --- |
| `compound-assignment` | Rewrite `x += 1` as `x = x + 1` |
| `unused-local` | Rename to `_name` to mark it intentionally unused |
| `net-unregistered` | Add `util.AddNetworkString("…")` at the top of the file |
| `net-never-received` | Append a `net.Receive` handler stub |
| `missing-addcsluafile` | Add `AddCSLuaFile("…")` above the include |
| `realm-violation` | Wrap the statement in `if SERVER then … end` |
| `unknown-hook` | Change to the closest matching hook names |

### Refactors

| Action | What it does |
| --- | --- |
| **Localise `math.floor`** | Hoists a repeatedly-used library function to `local math_floor = math.floor` at the top of the file. Offered when it is used at least twice |
| **Convert C-style operators to Lua** | Rewrites every `!=`, `&&`, `\|\|` and `!` in the document to `~=`, `and`, `or` and `not` |

## Editor features

Standard LSP features, available without a command:

- Completion, hover, signature help with overloads
- Go to definition, find all references, rename
- Document and workspace symbols
- Document highlights
- Semantic highlighting
- Inlay parameter hints
- Format document and format selection

Rename works on more than identifiers: renaming a **net message** or a **hook
name** string updates every registration, send and handler across the workspace.
